# Project configurations

| File | Project |
|---|---|
| `config.example.yaml` | Every setting with its default and a commented explanation (generated by `scripts/gen_config_reference.py`; the same text `osv init` writes). Copy it to start a new project. |
| `macban_tomo_2018-2019.yaml` | MacBan 2018-2019 (16 stations, OpenMEQ catalogue), fixed Vp/Vs from the Wadati diagram. Run directory `/media/steve/fast9100/runs/macban_tomo_2018-2019/velest`. |
| `macban_tomo_2018-2019_indS.yaml` | The same with an independent S velocity model. Run directory `.../macban_tomo_2018-2019/velest_indS`. |

The project configs use absolute paths for `project.workdir` and the input files, because
relative paths are resolved against the directory of the config file. Run them with, e.g.,
`osv run -c config/macban_tomo_2018-2019.yaml`. `tests/test_docs.py` checks that each file
here still validates against the schema.
