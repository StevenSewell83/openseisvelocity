## Program inventory (how the original scripts build them)

FMTOMO `compileall` (ksh): each program in `fmtomo/source/` is a single-file `gfortran -o <prog> <prog>.f90`:
arraygen, frechgen, gmtslice, grid3dg, invert3d, moddata, obsdata, residuals, synthdata, scorrect.
`fm3d` is built by `fmtomo/fmcode/Makefile` from mod_3dfm, 3dfmlib, propagate, rays, frechet, visual,
3dfm_main, matchref, teleseismic, svdlib, nn_subsf, stack, libsun, libtau, ellip, sphdist.
Teleseismic travel-time tables: `fmcode/aktimes` (`make all`, then run `remodl` and `setbrn` to produce
`ak135.tbl`/`ak135.hed`, copied to `source/inputfiles`); not needed for local earthquake tomography but fm3d links the tau code.
`tomo3d` is a ksh driver script that runs fm3d, frechgen/residuals/invert3d iteratively.

FMTOMO Extras `compile_all` (ksh): single-file programs in `fmtomo_extras/source/`:
frvpvs, gridloc, gridlocj, jointimes, mkvpvs, obsdatai, vpvsinv, vpvsresids, grid3dgi, gmtslicei, synthdatai;
ksh driver scripts tomo3di, tomo3dj, tomo3dps and cp_script are copied as-is. Extras programs rely on the
base FMTOMO fm3d and programs.

VELEST: single file `velest/velest.f` with include `velest_common.inc` (array limits), legacy fixed-form
Fortran 77; builds with `gfortran -std=legacy -ffixed-line-length-none`.
